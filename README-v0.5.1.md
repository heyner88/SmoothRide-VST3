# SmoothRide v0.5.1

This maintenance update keeps the v0.5.0 DSP, preset import/export, A/B matching, and performance telemetry unchanged.

## Changes

- Fixed the UI overlap where the starting preset selector could sit on top of the bottom parameter cards.
- Slightly reduced the parameter card height and moved the preset-management controls lower for better spacing.
- Kept the editor fixed at 1080 x 600 to preserve the stable window behavior in EqualizerAPO-XT.

## Testing focus

- Verify the preset selector no longer overlaps the configuration cards.
- Re-check open/close/reopen behavior and confirm preset import/export and A/B switching still work.
